# Mosaic Contracts

Technology-agnostic contracts for the Mosaic
Multi-Framework Mobile Architecture.

## Purpose

Define communication standards between the
Android Host, React Native Dashboard and Flutter Goals.

## Modules

- Navigation
- Events
- Module Metadata
- Shared Context

## Principles

- Technology agnostic.
- Explicit versioning.
- Backward compatibility whenever possible.
- Independently testable contracts.

## Status

Architecture foundation in progress.
